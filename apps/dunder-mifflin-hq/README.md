# Dunder Mifflin HQ app

The local web UI and server. To run it, use `npm ci && npm start` (http://localhost:4343). Run the tests with `npm test`.

Requires Node 22.13+ and a signed-in GitHub Copilot runtime for live chat. The full documentation
(teams, connectors, safety model and configuration) is in the [repository README](../../README.md).
Follow [Deployment and operations](../../docs/DEPLOYMENT.md) for installation, optional connector
setup, private data, updates and troubleshooting. This is a loopback-only, single-user application;
public web hosting is not supported.
